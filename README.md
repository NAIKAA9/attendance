# 📅 NAIK Study Tracker (90-Day Consistency Tracker)

An interactive, responsive 90-day consistency tracker built for logging study hours, tracking streak status, and planning topics for professional exams (like IBPS SO) and Java/Web development.

Built with a sleek custom dark/light color scheme, visual progress bars, interactive check-in cards, weekly score tracking, and automated client-side state preservation.

---

## 🚀 Live Demo
Visit the live tracker: **[https://eslavathnarasimhanaik.github.io/attendance/](https://eslavathnarasimhanaik.github.io/attendance/)**

---

## 🛠️ Tech Stack & Key Features
- **Core Technology**: Semantic HTML5, Vanilla JavaScript, and clean CSS (dynamic light/dark mode system tailored to HSL variables).
- **Professional Profile Hub**: Integrates a synced Developer Card with recruiter details, customizable skills, and links.
- **LinkedIn Smart Parser**: Client-side backup parser using regular expressions to extract name, headline, location, and skills from a copied LinkedIn page.
- **Dynamic SEO JSON-LD**: Dynamically builds and updates schema markup mapping all social identities.
- **Local Storage Engine**: Saves all checked-in data, upload logs, and profile edits client-side.
